# Portfolio Backend

Backend API for my personal portfolio website.

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Mongoose
- REST API

## Features

- Project CRUD APIs
- Contact form API
- MongoDB database integration
- CORS configuration

## API Endpoints

### Projects
- GET /api/projects
- POST /api/projects
- DELETE /api/projects/:id

### Contacts
- POST /api/contacts
